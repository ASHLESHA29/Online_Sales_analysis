# 📊 Online Sales Data Analysis (Python & SQL)

## 📌 Project Description
This project performs end-to-end data analysis on an online sales dataset from a popular marketplace.
Using Python for data cleaning, exploration, and visualization, and SQL for structured querying, the project aims to uncover meaningful business insights from real-world transactional data.

The analysis focuses on understanding sales trends, revenue distribution, product performance, and customer purchasing behavior, making it suitable for data analytics and business intelligence use cases.

## 📂 Dataset Information

Source: Kaggle – Online Sales Dataset (Popular Marketplace Data)
Type: E-commerce transactional data
Records: Individual sales transactions
Nature: Structured dataset suitable for SQL and Python analysis

## 📈 Key Analysis Performed

Monthly and yearly sales trends
Top revenue-generating products
Best performing product categories
Region-wise sales distribution
Payment method usage analysis
High-value vs low-value transactions
